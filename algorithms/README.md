# 算法组

自研方向的算法工作统一放这里：视觉识别、机器人决策。

## 方向说明

| 方向 | 内容 |
| --- | --- |
| 视觉识别 | 足球场（场地线、边界、球门等）、足球、机器人（己方与对方）的检测与定位；相机标定、数据集与标注、推理部署 |
| 机器人决策 | 根据场上态势做角色分配与行为选择：状态机 / 行为树 / 学习策略，输出给电控执行 |

## 需要提交什么

| 类型 | 内容 | 建议位置 |
| --- | --- | --- |
| 训练与推理代码 | 模型定义、训练脚本、推理与后处理 | `projects/<项目>/src/` |
| 模型权重 | 体积小的直接入库；大的用 Git LFS 或外链，并在 README 写清获取方式 | `projects/<项目>/models/` |
| 数据集说明 | 采集条件、标注规则、划分方式；原始数据不入库 | `projects/<项目>/data/README.md` |
| 标定参数 | 相机内参、外参、坐标系定义 | `projects/<项目>/calib/` |
| 实验结果 | 指标、对比曲线、失败案例分析 | `projects/<项目>/README.md` |
| 决策策略 | 策略代码、参数、状态定义 | `projects/<项目>/decision/` |

## 不需要提交什么

- 原始数据集和标注文件（放外部存储，仓库里只留说明和下载方式）
- 训练中间检查点
- 依赖虚拟环境和缓存
- 密钥和第三方授权数据

## 目录

项目统一放在 `projects/` 下，一个项目一个子目录，具体要求和命名见 [projects/README.md](projects/README.md)。
