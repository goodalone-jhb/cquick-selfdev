# projects · 算法组项目

算法组的每个项目在这里建一个子目录，一个项目一个目录。

## 命名

英文小写加连字符，能看出是做什么的：`vision-detection`、`ball-tracking`、`robot-decision`、`field-localization`。

## 每个项目至少要有什么

```text
<项目名>/
├── README.md      做什么、怎么跑、结论是什么
├── src/           模型定义、训练与推理代码
├── models/        权重（小文件入库，大文件给链接）
├── data/          小体积样本 + README 说明采集与标注条件
├── calib/         相机标定参数与坐标系说明
└── decision/      决策策略代码与参数
```

用不到的目录不用建，用到了再补。

## README 里必须写清

1. 这个项目解决什么问题、属于视觉还是决策
2. 输入输出是什么（图像分辨率、坐标系、输出类别或动作）
3. 怎么跑：环境依赖、训练命令、推理命令，能直接复制执行
4. 结果：指标数字（准确率、召回、延迟），有对比就放对比
5. 当前状态和已知问题

## 提交要求

- 依赖版本固定（`requirements.txt`），保证别人能复现
- 数据不入库，但采集条件、标注规则、训练/验证划分必须写清楚
- 模型权重超过 10MB 用 Git LFS 或外链，不要直接塞进提交
- 失败的实验和参数组也记下来，写进 README 或 `notes.md`，避免重复试错
- 决策逻辑改动要说明对下游（电控执行）的影响
