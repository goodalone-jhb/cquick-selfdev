# tools · 脚本工具

放仓库自己用的小工具：文档检查、批量处理、数据转换等。不放项目业务代码。

## 现有工具

| 脚本 | 用途 | 用法 |
| --- | --- | --- |
| `check_docs.py` | 检查 Markdown 的相对链接、代码围栏是否成对、文件结尾换行 | `python tools/check_docs.py` |

`check_docs.py` 会在 CI 里自动运行（`.github/workflows/docs-check.yml`），提交前本地跑一遍能省一次返工。

## 新增脚本的要求

1. 只用 Python 标准库，避免为了一个检查脚本引依赖
2. 文件头写清用途、用法、退出码含义
3. 能在仓库根目录直接运行：`python tools/<脚本名>.py`
4. 加进上面的表格，一句话说明用途
5. 有输出的脚本，正常结束返回 0，发现问题返回非 0（CI 靠退出码判断）

## 不放什么

- 一次性的数据清洗脚本（放对应项目目录）
- 训练、推理代码（属于算法组项目）
- 需要登录、密钥才能跑的东西
