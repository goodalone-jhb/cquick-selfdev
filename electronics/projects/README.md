# projects · 电控组项目

电控组的每个项目在这里建一个子目录，一个项目一个目录。

## 命名

英文小写加连字符，能看出是做什么的：`joint-node`、`limb-motor-driver`、`host-ethercat`、`rl-locomotion`。

## 每个项目至少要有什么

```text
<项目名>/
├── README.md      项目是做什么的、怎么编译烧录、当前状态、已知问题
├── firmware/      节点或设备端固件（源码 + 工程配置，含编译命令）
├── protocol/      通信协议定义：帧格式、报文、对象字典、节点寻址
├── host/          上位机程序（主站、监控、调试）
├── hardware/      原理图、PCB、BOM、pinmap.md
└── notes.md       调试记录：现象、排查过程、结论
```

用不到的目录不用建，用到了再补。

## README 里必须写清

1. 这个项目解决什么问题、属于哪条技术线（关节通信 / 强化学习 / 上位机）
2. 怎么编译、怎么烧录、怎么运行，命令要能直接复制执行
3. 依赖的工具和版本（编译器、SDK、Python 包）
4. 当前状态和已知问题

## 提交要求

- 通信相关的改动，必须同时更新 `protocol/` 里的协议文档，避免上下游对不上
- 硬件改了引脚，同一次提交里改 `hardware/pinmap.md` 和固件里的引脚定义
- 固件只提交源码和工程配置，产物不入库
- 调试记录随手写进 `notes.md`，按日期分段，别只留在聊天记录里
