# 电控组

自研方向的电控工作统一放这里：关节末端通信、强化学习动作训练、上位机网络通信。

## 方向说明

| 方向 | 内容 |
| --- | --- |
| 关节末端通信 | 每条肢体一个节点。节点向下通过 FDCAN 连接肢体内电机，向上通过 EtherCAT 菊花链连接上位机；负责电机指令下发与状态回读、本节点数据采集、节点间转发、故障上报 |
| 强化学习动作训练 | 动作策略的训练工程与部署：训练环境、观测与奖励设计、训练配置、sim2real 落地验证 |
| 上位机网络通信 | 上位机与机器人之间的通信链路：EtherCAT 主站、调试下行、数据回传与状态监控 |

## 需要提交什么

| 类型 | 内容 | 建议位置 |
| --- | --- | --- |
| 节点固件 | 源码、工程配置、编译说明 | `projects/<项目>/firmware/` |
| 通信协议 | 帧格式、报文定义、对象字典、节点寻址 | `projects/<项目>/protocol/` 或 `docs/` |
| 上位机程序 | 主站程序、监控界面、调试工具 | `projects/<项目>/host/` |
| 训练工程 | 环境配置、训练脚本、参数文件、部署代码 | `projects/<项目>/rl/` |
| 硬件资料 | 原理图、PCB、BOM、引脚分配表 | `projects/<项目>/hardware/` |
| 调试记录 | 现象、原因、结论、实测数据 | `projects/<项目>/notes.md` |

## 不需要提交什么

- 编译中间产物和调试器临时文件（`.gitignore` 已覆盖）
- 大体积日志、抓包文件、训练数据集
- 密钥、内网地址、WiFi 密码
- 别人未授权的资料

## 目录

项目统一放在 `projects/` 下，一个项目一个子目录，具体要求和命名见 [projects/README.md](projects/README.md)。
