# 文档

放跨组的规范、说明和长期参考文档。各组项目自己的文档放在各自的项目目录里。

## 需要提交什么

| 内容 | 说明 |
| --- | --- |
| 通信协议 | 节点与上位机、组间的接口定义，避免两边实现不一致 |
| 接口约定 | 坐标系、单位、消息字段、状态码 |
| 命名与目录规范 | 引脚命名、文件命名、项目命名 |
| 部署与使用说明 | 环境怎么搭、程序怎么跑、常见问题 |
| 选型与方案记录 | 为什么这么做、放弃过什么方案 |

## 约定

- 文件名用英文小写加连字符，如 `can-protocol.md`
- 一个文件写一件事，不要什么都往一个文件里堆
- 新增文档后在本文件下方列出，一句话说明内容
- 文档内容过期就更新或标注"已归档"，不要留着误导后人
