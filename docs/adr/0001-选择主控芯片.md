# 0001 选择 PY32F002BF15P6 作为猫耳头带主控

- 状态：已采纳
- 日期：2026-11-24
- 决策人：@goodalone-jhb
- 相关 Issue：（待补）

## 背景

猫耳头带需要在指甲盖大小的 PCB 上完成：读取 MPU6050 姿态、驱动两路舵机跟随头部动作、
保留调试串口。约束条件：

- 单板成本必须压到极低，属消耗件，坏了能换
- 封装要小，TSSOP20 / QFN20 级别
- 交期稳定，不能依赖长期缺货的型号
- 算力只需支撑 100Hz 一阶滤波 + 双路 PWM

## 备选方案

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| PY32F002BF15P6 | 成本极低、TSSOP20 小封装、供货稳定、24MHz Cortex-M0+ 够用 | 生态资料少、官方库不如 ST 完善、调试踩坑需自己解决 |
| STM32F030F4 | 生态成熟、资料多、CubeMX 支持 | 单价偏高，缺货周期不确定 |
| GD32E230F8 | 性能强、兼容 ST 生态 | 封装偏大、成本高于 PY32 |
| ESP32-C3 | 自带无线、算力充足 | 功耗高、成本高、对纯本地动作控制是浪费 |

## 结论

选 PY32F002BF15P6。核心逻辑所需的算力与引脚数它刚好够，成本优势在同价位里最明显。

## 后果

- 正面：单板成本显著下降，可批量做备用板
- 正面：TSSOP20 手工焊接友好，打样迭代快
- 负面：Flash / RAM 紧张，姿态解算不能上 EKF，需用互补滤波
- 负面：无成熟 IDE 工程模板，需自行配置 EIDE + arm-none-eabi 工具链并入库
- 负面：缺少 DMP 之外的硬件加速，浮点全部软件模拟，控制周期需实测确认

## 推翻条件

- 需要跑更复杂的解算（EKF / 多传感器融合）导致算力不足
- 供货出现长期断档
- 需要 CAN、USB 等 PY32F002B 不具备的外设
